Закупки студенческого мини-маркета

LOGIN

Добавляйте закупки, редактируйте их и отмечайте выполненные. Данные должны сохраняться после перезагрузки.

Задание разработчику

Измените LOGIN и реализуйте purchaseTask(command). Интерфейс и проверочный контракт оставьте без изменений.

Ключ: webtech.minimarket.purchases.v1. Храним JSON-массив записей {id,title,quantity,completed}. Название: 1–100 символов после trim; количество: целое число 1–999; статус: boolean. Одинаковые названия допустимы.

Эта заготовка намеренно возвращает not-implemented. Полные требования и открытые испытания находятся в PDF-инструкции.

Новая закупка

Реализуйте purchaseTask в студенческом блоке.

Список закупок

Пока закупок нет. Добавьте первую запись через форму.

Результат последней операции

{
  "ok": false,
  "error": "not-implemented"
}

Проверка перед сдачей

  1. Создайте две записи с одинаковым названием.
  2. Перезагрузите страницу: записи и их id должны сохраниться.
  3. Измените одну запись и отметьте её как закупленную.
  4. Удалите вторую запись, затем снова перезагрузите страницу.
  5. Проверьте пустое название и дробное количество: данные не должны измениться.

Опубликуйте страницу по HTTPS и сдайте ссылку в назначенный преподавателем форум Moodle. Для локальной работы используйте HTTP-сервер; итоговую проверку проводите по опубликованному адресу.
